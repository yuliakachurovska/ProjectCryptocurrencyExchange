# ProjectCryptocurrencyExchange
"Cryptocurrency Exchange" Software Development Project

# Біржа криптовалют (CryptoExchange)

Android-застосунок для моніторингу актуальних курсів топ-30 криптовалют відносно долара США (`USD`) з підтримкою офлайн-режиму, фонової синхронізації та адаптивного інтерфейсу.

## Автор
* **Виконала:** Качуровська Юлія та Александрова Анна

## Основний функціонал
* **Топ-30 криптовалют у реальному часі:** відображення місця в рейтингу, логотипа, тикера (`BTC / USD`), повної назви та актуальної ціни з точним форматуванням мікроцін (до 8 знаків після коми).
* **Екран детальної інформації:** перегляд добового мінімуму (`Low 24h`) та максимуму (`High 24h`), джерела даних і часу останнього оновлення.
* **Offline-first:** збереження курсів у локальну базу даних **Room**. Застосунок коректно працює та відображає збережені дані без підключення до Інтернету.
* **Ручне та фонове оновлення:** кнопка «Оновити» на головному екрані + автоматична фонова синхронізація щогодини з відображенням статусів (очікування мережі, синхронізація, помилка).
* **Адаптивний інтерфейс та теми:**
  * *Портретна орієнтація:* навігація між списком монет та екраном деталей із підтримкою системної кнопки «Назад».
  * *Альбомна орієнтація:* двопанельний режим (список монет ліворуч, деталі обраної монети праворуч) зі збереженням позиції прокрутки та вибору при повороті екрана.
  * *Світла та темна теми:* автоматична адаптація кольорової схеми.

## Джерело даних та налаштування синхронізації
* **API:** публічний REST API [CoinGecko API v3](https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=30&page=1) (не потребує API-ключа).
* **Інтервал періодичного фонового оновлення:** **1 година** (`PeriodicWorkRequest` у `WorkManager`).
* **Обмеження та політики WorkManager:** обов'язкова наявність мережі (`NetworkType.CONNECTED`), запобігання дублюванню задач (`ExistingWorkPolicy.KEEP` / `ExistingPeriodicWorkPolicy.KEEP`) та автоматичний повтор при тимчасових збоях (`Result.retry()`).

## Архітектура та технологічний стек
Проєкт побудовано за принципами **Clean Architecture** та патерном **MVVM** з односпрямованим потоком даних (UDF):
* **Мова:** Kotlin
* **UI:** Jetpack Compose, Material Design 3
* **Завантаження зображень:** Coil 3 (`coil-compose`, `coil-network-okhttp`)
* **Асинхронність та реактивність:** Kotlin Coroutines, `StateFlow`, `Flow`
* **Мережа:** Retrofit 2, OkHttp, Gson
* **Локальна база даних:** Room (з атомарним `@Transaction` оновленням списку топ-30)
* **Фонові задачі:** AndroidX WorkManager (`CoroutineWorker`)

### Структура пакетів
* `domain/` — бізнес-моделі (`CryptoCurrency`, `SyncResult`), контракт репозиторію (`CryptoRepository`) та UseCase-и (`ObserveTopCryptosUseCase`, `SyncTopCryptosUseCase`).
* `data/` — мережевий шар (`CoinGeckoApi`, `RetrofitClient`, DTO), локальна БД Room (`CryptoDatabase`, `CryptoDao`, `CryptoCurrencyEntity`) та реалізація репозиторію (`CryptoRepositoryImpl`).
* `worker/` — фоновий воркер (`CryptoSyncWorker`) та планувальник задач (`CryptoSyncScheduler`).
* `presentation/` — `CryptoViewModel`, `CryptoUiState`, форматування даних та Compose-компоненти екранів.
* `di/` — ручний контейнер залежностей (`AppContainer`).
